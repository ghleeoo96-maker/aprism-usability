# 에이프리즘 사용성 평가

로봇 안전진단 관제 플랫폼 에이프리즘의 사용성 평가(UT) 진행 사이트.

- 진행: 참가자 선택 → 사전 질문 → 튜토리얼 → 시나리오 1~3 → 공통질문
- 기록: 테스트 화면 안 클릭, 시나리오 수행 시간, 사전 질문과 공통질문 답. 브라우저(localStorage)에만 저장되고 이 저장소에는 올라오지 않는다
- 모으기: 노트북마다 기록 화면의 [전체 JSON]으로 내보낸 뒤 한 곳에서 [JSON 가져오기]로 합친다
- 리포트: 처음 화면 [리포트]. 샘플은 주소 끝 `#report-sample`, 튜토리얼 미리보기는 `#tour`

`app/` 은 에이프리즘 관제 화면(aprism-web) 복사본이다. 테스트 기간 동안 화면이 바뀌지 않게 고정해 두었다(`app/.snapshot` 의 커밋).

로컬에서 열 때: `node serve.mjs` 또는 `열기.bat` → http://localhost:5299/
관제 화면은 3D 라이브러리와 폰트를 인터넷에서 받으므로 인터넷 연결이 필요하다.

## 온라인 백업(구글 시트)

기록은 세 겹으로 남는다. ① 브라우저 저장소(클릭할 때마다) ② 참가자가 끝날 때 내려받는 JSON 파일 ③ 구글 시트와 드라이브(시나리오가 끝날 때마다, 실패하면 1분마다 다시).

③ 켜는 법
1. 구글 시트를 새로 만든다 → 확장 프로그램 → Apps Script
2. `ut-backup.gs` 내용을 통째로 붙여 넣고 저장
3. 배포 → 새 배포 → 유형 "웹 앱", 실행 계정 "나", 액세스 권한 "모든 사용자" → 배포 → 권한 허용
4. 나온 웹 앱 주소(…/exec)를 `index.html` 의 `CLOUD_URL` 에 넣는다(또는 기록 화면 [백업 주소 넣기])

기록 전체는 드라이브 "aprism-ut-records" 폴더에 기록마다 JSON 파일로, 시트 "기록" 탭에는 한 줄 요약으로 남는다.
